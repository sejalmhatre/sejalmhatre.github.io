Mail Attachment Sync

Mail Attachment Sync is a small private tool. It copies attachments from the owner's own Zoho Mail inbox into the owner's own Google Drive, so that the owner can search and read them there. It uses Google's Drive permission that only allows the tool to manage files it created itself (drive.file). It does not read, change or delete any other file in Google Drive.

The tool is not offered to the public and has no sign-up.
